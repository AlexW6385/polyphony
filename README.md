# Polyphony

> A mind is a polyphony: many voices, no conductor.

Polyphony simulates the inside of a head: several AI agents — *voices*, each
with its own values and temperament — watch one shared stream of thoughts and
independently decide whether to add to it. Nobody schedules them, nobody
moderates them, and nobody tells them when to stop.

Design notes: [`docs/DESIGN.md`](docs/DESIGN.md). Code is not here yet.
